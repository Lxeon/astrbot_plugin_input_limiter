# astrbot_plugin_input_limiter

按**人格**限制用户输入长度，超长自动截断，从源头节约 token。
适合"系统提示词已限定 bot 只做某件事，但用户仍灌大段无关文字"的场景。

## 功能

- 按人格独立配置：每个人格一条规则，互不影响
- 默认不开启：规则列表为空时不限制任何会话
- 只截文本：图片 / 文件 / At 等非文本内容原样保留
- 不阻断对话：截断后事件照常流向 AI
- 跳过斜杠指令：`/xxx` 开头的消息不截断，避免指令被截短后无法识别
- 人格识别带 8 秒缓存：不会每条消息都查数据库
- 配置自动持久化，重启不丢

## 配置项

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| debug_log | bool | false | 调试日志，排错时开 |
| rules | 列表 | [] | 人格规则，见下 |

每条规则：

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| persona | 下拉/文本 | - | 人格名称 |
| enabled | bool | false | 该规则开关 |
| max_length | int | 100 | 文本总长度上限（截断后缀不计入，实际最长会超出后缀的几个字） |
| suffix | string | ...(已截断) | 截断后缀 |
| skip_admin | bool | false | AstrBot 全局管理员豁免（admins_id 中的人，不是群管理员/群主） |

## 使用（三步）

1. 启用插件，进入插件设置
2. 在「人格输入限制规则」点**添加**，选/填人格名，**打开『启用该规则』**，设字数
3. 保存。没加规则的人格完全不受影响

> 想给多个人格限制？在列表里继续添加规则即可，无需重装。

## 安装

将 `astrbot_plugin_input_limiter` 文件夹放入 `data/plugins/`，在 WebUI 插件管理中启用并重载。

## FAQ（排错）

**Q：装了但完全没截断？**
在目标会话用**全局管理员账号**发 `/inputlimiter`（该指令仅管理员可用），看输出逐项核对：
- 「规则数」为 0 → 没加规则，不会生效。
- 规则里的 `enabled` 是 False → 添加规则后默认是关的，必须手动打开。
- 「识别到的人格名」与规则里的「人格」对不上 → 照它显示的名字填（不区分大小写）。

**Q：识别到的人格名是 `default`，我有多个配置文件想分开管？**
说明这些配置文件共用了同一个人格，人格这一维区分不开。此方案不适用，需改用群号 / 机器人账号白名单方案。

**Q：webchat 平台填 default 匹配不到？**
webchat 平台的默认人格会被识别为 `_chatui_default_`（不是 `default`），规则里的人格名请填 `_chatui_default_`。以 `/inputlimiter` 实际显示的名字为准。

**Q：用 /persona 切换人格后，限制多久生效？**
人格识别结果按会话缓存约 8 秒，切换后最坏 8 秒内生效，无需重启。

**Q：日志显示已截断，但 token 没降？**
确认是否真的重载了插件、配置是否保存成功；并打开 `debug_log` 看是否打印「已截断 X -> Y 字符」。若仍异常，把控制台 `[InputLimiter]` 日志反馈给作者。

**Q：怎么开调试日志？**
插件设置里把「调试日志开关」打开并保存，发一条消息后看控制台 `[InputLimiter]` 开头的行。排错完建议关掉。

**Q：截断会把图片/文件也删掉吗？**
不会。只截 `Plain` 文本组件，其余原样保留。
